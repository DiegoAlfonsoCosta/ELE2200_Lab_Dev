\section{Theoretical Background}
\label{sec:theory}

The theoretical analysis is based on standard principles introduced in class.
The system is modeled using ideal assumptions in order to obtain a closed-form
analytical expression.

Let the input variable be denoted by $x(t)$ and the output by $y(t)$. Under linear
operating conditions, the system behavior can be expressed as
\[
y(t) = K x(t),
\]
where $K$ is a constant gain parameter.

These theoretical results will be used as a reference to interpret the experimental
data obtained in the laboratory.
